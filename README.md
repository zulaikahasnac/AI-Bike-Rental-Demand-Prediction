# AI-Based Bike Rental Demand Prediction Using Machine Learning

## Project Overview

This project aims to predict hourly bike rental demand using machine learning techniques and recent historical data.

The proposed system will analyze Capital Bikeshare trip records from 2025 along with weather information from Open-Meteo to identify rental demand patterns.

## Objectives

- Collect and preprocess bike rental and weather data.
- Analyze hourly, daily, and seasonal demand patterns.
- Develop and compare machine learning regression models.
- Evaluate performance using MAE, RMSE, and R².
- Support data-driven bike rental demand planning.

## Dataset

- **Bike Rental Data:** [Capital Bikeshare](https://capitalbikeshare.com/system-data)
- **Weather Data:** [Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api)
- **Study Period:** January–December 2025 (planned)

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, and GitHub.

## Proposed Machine Learning Models

1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. Gradient Boosting Regressor
